# GlobeTrotr

GlobeTrotr is een smart travel dashboard / reisplanner.

## Belangrijk

- Dit is een bestaand Lovable-project.
- Behoud bestaande functionaliteit.
- Verwijder geen bestaande features tenzij daar expliciet om gevraagd wordt.
- Verander de bestaande styling niet onnodig.
- Controleer eerst de bestaande code voordat je wijzigingen maakt.
- Werk binnen de bestaande architectuur.
- Maak geen compleet nieuwe app wanneer een bestaande component aangepast kan worden.

## Werkwijze

1. Analyseer eerst de relevante bestanden.
2. Leg kort uit wat je gaat veranderen.
3. Pas alleen noodzakelijke bestanden aan.
4. Controleer of bestaande functionaliteit behouden blijft.
5. Controleer op syntax-/buildfouten.
6. Geef na afloop een korte samenvatting van de wijzigingen.

## Lovable

De codebase wordt ook door Lovable gebruikt.

Wijzigingen moeten daarom:
- overzichtelijk blijven;
- bestaande componenten zoveel mogelijk hergebruiken;
- geen onnodige dependencies toevoegen;
- geen grote architectuurwijzigingen maken zonder toestemming.
