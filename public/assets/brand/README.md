# GlobeTrotr brand assets

These files are served directly by the production web container:

- `/assets/brand/logo.png` — square application mark
- `/assets/brand/header.png` — horizontal green wordmark
- `/assets/brand/monochrome-black.png` — monochrome wordmark
- `/assets/brand/dark.png` — wordmark for dark surfaces
- `/assets/brand/full.png` — full light brand mark
- `/assets/email/logo.png` — compact logo used in transactional email

Keep these paths stable because websites and email templates may cache them.
