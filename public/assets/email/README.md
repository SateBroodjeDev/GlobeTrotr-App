# Openbare e-mailassets

Bestanden in deze map worden bij iedere webdeployment rechtstreeks onder
`https://globetrotr.nl/assets/email/` gepubliceerd. Gebruik alleen kleine,
geoptimaliseerde afbeeldingen zonder persoonsgegevens. Vervang `logo.png` in
Git om het logo in toekomstige GlobeTrotr-appmails bij te werken.
