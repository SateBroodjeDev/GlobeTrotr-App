# GlobeTrotr roadmap

GlobeTrotr richt zich in de eerste plaats op vriendengroepen, koppels en families die samen een reis plannen en kosten verdelen. Agency-functionaliteit blijft beschikbaar als premium optie voor reisorganisaties.

## Fase 1 — Accounts & privacy (klaar)

- [x] E-mailregistratie, inloggen en uitloggen via Supabase Auth
- [x] Privé workspace per account met Row Level Security
- [x] Cloud-sync van reizen en instellingen, met lokale per-account cache
- [x] Publieke homepage voor bezoekers zonder account

## Fase 2 — Samen reizen en geld (klaar)

- [x] Multi-valuta en live koersomrekening
- [x] Brandstof- en autokostencalculator
- [x] Eerlijke kostenverdeling voor groepen, met minimaal aantal terugbetalingen
- [x] Tripstatus, afteller, paklijsten en voortgang
- [x] Start- en einddatum van een reis aanpassen

## Fase 3 — Delen (klaar)

- [x] Reis per keuze openbaar maken of weer privé zetten
- [x] Publieke reispagina via een niet-voorspelbare token-URL
- [x] Openbare reizen tonen op de homepage
- [x] PIN-beveiliging per gedeelde reis
- [x] Keuze om het budget per openbare reis te delen

## Fase 4 — Documenten & export (deels klaar)

- [x] CSV- en JSON-back-up/export
- [x] Printklare reisgids met Google Maps-navigatie per stop
- [x] PDF-reisoverzicht
- [ ] Bonnetjes uploaden en koppelen aan een uitgave (de beveiligde opslagregels bestaan al)

## Fase 5 — Abonnementen & Agency

- [x] Free-, Pro- en Agency-plannen met accountgebonden cloudopslag
- [x] Plan wijzigen met bevestigde opslag in Supabase
- [x] Agency-only: white-label, rollen, analytics en declarabele klantuitgaven
- [ ] Betalingen en facturen koppelen aan een betaalprovider, bijvoorbeeld Stripe
